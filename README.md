# JavaScript Order System

A simple JavaScript project that collects user information, allows users to select a food order, and checks order eligibility based on age.

## Features

- Collects the user's name, age, and gender.
- Displays a personalized welcome message.
- Allows users aged 16 or older to place an order.
- Provides three food options: Burger, Shawarma, and Zinger.
- Validates the selected order.
- Confirms valid orders for users aged 18 or older.
- Displays user information and order status.

## Technologies Used

- HTML5
- JavaScript

## How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Enter your information and select your order.
